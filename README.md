# HoneybunnyPot

HoneybunnyPot is a simple HTTP honeypot that logs incoming requests and displays them through a Flask-based dashboard. It's designed for learning, local experimentation, and observing basic unauthorized scanning or access behavior.

## Description

This project consists of two components:
- A Python honeypot that listens on a specific port and logs incoming requests.
- A Flask web dashboard that reads and displays those logs in real-time.# HoneybunnyPot

A fun honeypot project to trap suspicious activity and visualize logs.
